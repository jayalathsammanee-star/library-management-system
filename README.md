# Online Library Management System

A web-based Library Management System developed using PHP and MySQL. This project helps manage library operations such as student registration, book management, book requests, and book issuing.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Main Features

- Student Registration
- Student Login and Logout
- View Available Books
- Search and Browse Books
- Request Books
- Manage Issued Books
- View Book Issue Information
- Track Expired Books
- Feedback Section

## Project Structure

- `bootstrap/` - Bootstrap files
- `database/` - Database files
- `images1/` - Project images
- PHP files - Application pages and functionality
- `style.css` - Custom styling

## Installation and Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the XAMPP `htdocs` directory.
4. Open phpMyAdmin.
5. Create the database using the database name configured in the project.
6. Import the SQL file from the `database` folder.
7. Configure the database connection using `connection.example.php`.
8. Open the project in your browser using localhost.
